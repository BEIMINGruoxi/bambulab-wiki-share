Bambu Lab P1 打印机延续了 X1 系列优异的运动控制技术，包括 AMS 兼容性。

![图片](https://wiki.bambulab.com/p1/manual/ams-connection/1.png)

将 AMS 连接到 P1 打印机后，在 Bambu Studio 和 Bambu Handy 上控制和操作 AMS 的方法与在 X1 上基本一致。

本文只介绍 AMS 与 P1 系列的连接方式；关于 AMS 的控制和操作，请看 X1 系列的三个 wiki 视频和文字教程。

- [连接 AMS 到 X1/X1C](https://wiki.bambulab.com/zh/x1/manual/connect-ams)
- [AMS 配置和上料步骤](https://wiki.bambulab.com/zh/x1/manual/ams-setup-and-filament-loading)
- [连接 AMS Hub 和多台 AMS](https://wiki.bambulab.com/zh/x1/manual/Connect-AMS-Hub-and-multi-AMS)

在使用 AMS 之前，请阅读 [AMS 的简介](https://wiki.bambulab.com/zh/x1/manual/intro-ams) ，以熟悉该系统。你也应该提前阅读 [AMS 的注意事项](https://wiki.bambulab.com/zh/knowledge-sharing/notes-AMS) ，规范使用 AMS。

### 如何将 AMS 连接到 P1 系列打印机上

请按照以下步骤将 AMS 系统连接到 P1 系列打印机。

步骤 1：如图所示，连接 PTFE 管、6 pin 总线和 4 pin 总线。

![图片](https://wiki.bambulab.com/p1p_的接线方式.png)

P1P 的接线方式

![图片](https://wiki.bambulab.com/p1/manual/ams-connection/p1s-ams.png)

P1S 的接线方式

### 第二步：如果打印机屏幕上显示 AMS 图标，说明 AMS 连接成功

![图片](https://wiki.bambulab.com/p1/manual/ams-connection/3.png)

### 第三步：连接成功后，你还可以在系统设置目录中查找 AMS 的固件版本和 SN 号。
